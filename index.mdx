## What are Snakemake Wrappers?

The Snakemake Wrapper Repository is a collection of reusable wrappers that allow you to quickly use popular command line tools from [Snakemake](https://snakemake.readthedocs.io) rules and workflows.

<Info>
Each wrapper provides a standardized interface to bioinformatics tools, handling input/output parsing, parameter management, and integration with Snakemake's resource management.
</Info>

## Quick example

Here's a simple example using the FastQC wrapper:

```python
rule fastqc:
    input:
        "reads/{sample}.fastq",
    output:
        html="qc/fastqc/{sample}.html",
        zip="qc/fastqc/{sample}_fastqc.zip",
    params:
        extra="--quiet",
    log:
        "logs/fastqc/{sample}.log",
    threads: 1
    resources:
        mem_mb = 1024,
    wrapper:
        "master/bio/fastqc"
```

## Available wrappers

We provide wrappers for hundreds of bioinformatics tools, including:

- **Alignment**: BWA, Bowtie2, STAR, HISAT2, Minimap2
- **Variant calling**: GATK, FreeBayes, VarScan, Strelka
- **Quality control**: FastQC, MultiQC, Qualimap
- **RNA-seq**: Salmon, Kallisto, RSEM, STAR
- **Assembly**: SPAdes, MEGAHIT, Canu
- **And many more...**
