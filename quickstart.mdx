## Prerequisites

Before you begin, make sure you have:

- [Snakemake](https://snakemake.readthedocs.io) ≥5.7.0 installed
- Access to the internet (for downloading wrapper files)
- Basic understanding of Snakemake workflows

## Install Snakemake

If you haven't installed Snakemake yet, you can install it using conda:

```bash
conda install -c bioconda -c conda-forge snakemake
```

Or using pip:

```bash
pip install snakemake
```

## Your first wrapper

<Steps>
  <Step title="Create a workflow file">
    Create a new file called `Snakefile` in your project directory.
  </Step>
  
  <Step title="Add a wrapper rule">
    Add a rule that uses a wrapper. Here's an example using FastQC:
    
    ```python
    rule fastqc:
        input:
            "reads/{sample}.fastq",
        output:
            html="qc/fastqc/{sample}.html",
            zip="qc/fastqc/{sample}_fastqc.zip",
        log:
            "logs/fastqc/{sample}.log",
        threads: 1
        wrapper:
            "master/bio/fastqc"
    ```
  </Step>
  
  <Step title="Run your workflow">
    Execute your workflow with Snakemake:
    
    ```bash
    snakemake --use-conda -j 1
    ```
    
    The `--use-conda` flag tells Snakemake to automatically create conda environments for the wrappers.
  </Step>
</Steps>

<Check>
  You should see Snakemake downloading the wrapper, creating the conda environment, and running FastQC on your input files.
</Check>

## Understanding wrapper syntax

Wrappers are referenced using the `wrapper:` directive in your rules:

```python
wrapper: "master/bio/fastqc"
```

The format is:
- `master` - the branch/tag of the wrapper repository
- `bio` - the category (bio for bioinformatics tools)
- `fastqc` - the tool name

## Common wrapper parameters

Most wrappers support common parameters:

<ParamField path="input" type="file or list" required>
  Input file(s) required by the tool. Can be a single file or a list of files.
</ParamField>

<ParamField path="output" type="file or dict" required>
  Output file(s). Can be a single file or a dictionary with named outputs.
</ParamField>

<ParamField path="params" type="dict">
  Additional parameters specific to the tool. See individual wrapper documentation for available options.
</ParamField>

<ParamField path="threads" type="integer">
  Number of threads to use. Defaults to 1 if not specified.
</ParamField>

<ParamField path="resources" type="dict">
  Resource requirements (memory, runtime, etc.) for the rule.
</ParamField>

<ParamField path="log" type="file">
  Log file path for capturing stdout and stderr.
</ParamField>
