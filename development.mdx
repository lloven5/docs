## Prerequisites

Before you can develop or test wrappers locally, you need:

- Python 3.7 or higher
- Conda or Mamba
- Git
- Snakemake ≥5.7.0

## Setting up the development environment

<Steps>
  <Step title="Clone the repository">
    Clone the repository to your local machine:
    
    ```bash
    git clone https://github.com/snakemake/snakemake-wrappers.git
    cd snakemake-wrappers
    ```
    
    Or if you've forked the repository:
    
    ```bash
    git clone https://github.com/YOUR_USERNAME/snakemake-wrappers.git
    cd snakemake-wrappers
    ```
  </Step>
  
  <Step title="Install dependencies">
    Install the required Python packages:
    
    ```bash
    pip install pytest pytest-cov pyyaml
    ```
    
    Or use conda:
    
    ```bash
    conda install pytest pytest-cov pyyaml
    ```
  </Step>
  
  <Step title="Install Snakemake">
    Make sure you have Snakemake installed:
    
    ```bash
    conda install -c bioconda -c conda-forge snakemake
    ```
    
    Or:
    
    ```bash
    pip install snakemake
    ```
  </Step>
</Steps>

## Testing wrappers

### Running all tests

Run the complete test suite:

```bash
pytest test_wrappers.py -v
```

### Testing a specific wrapper

Test a single wrapper:

```bash
pytest test_wrappers.py::test_fastqc -v
```

### Testing with specific options

Run tests with additional options:

```bash
# Show print statements
pytest test_wrappers.py -v -s

# Stop on first failure
pytest test_wrappers.py -v -x

# Run tests in parallel
pytest test_wrappers.py -v -n auto
```

### Testing modified wrappers only

If you've modified wrappers, you can test only changed ones:

```bash
# Test wrappers changed compared to master
DIFF_MASTER=true pytest test_wrappers.py -v

# Test wrappers changed in last commit
DIFF_LAST_COMMIT=true pytest test_wrappers.py -v
```

### Containerized testing

Run tests in containers:

```bash
CONTAINERIZED=true pytest test_wrappers.py -v
```

## Creating test workflows

### Test structure

Each wrapper should have a test directory:

```
bio/toolname/
├── wrapper.py
├── meta.yaml
├── environment.yaml
└── test/
    ├── Snakefile
    └── data/
        └── test_input.txt
```

### Test Snakefile

Your test Snakefile should:

1. Use the wrapper
2. Include realistic test data
3. Verify outputs are produced
4. Test common use cases

Example:

```python
rule test_tool:
    input:
        "test/data/input.txt",
    output:
        "test/output.txt",
    params:
        extra="--flag value",
    log:
        "test/logs/tool.log",
    wrapper:
        "master/bio/toolname"

rule all:
    input:
        "test/output.txt"
```

## Local wrapper development

### Testing wrappers locally

When developing a wrapper, you can test it locally:

```python
# In your Snakefile
rule test:
    input:
        "input.txt",
    output:
        "output.txt",
    wrapper:
        "../bio/toolname"  # Relative path to your wrapper
```

### Using local wrapper repository

To use a local wrapper repository in your workflow:

```python
rule example:
    wrapper:
        "file:///path/to/snakemake-wrappers/bio/toolname"
```

Or set the wrapper base directory:

```bash
snakemake --wrapper-prefix file:///path/to/snakemake-wrappers
```

## Debugging

### Enable verbose logging

Get more detailed output:

```bash
snakemake --verbose
```

### Check wrapper execution

Add debug prints to your wrapper:

```python
import sys
print(f"Input: {snakemake.input}", file=sys.stderr)
print(f"Output: {snakemake.output}", file=sys.stderr)
```

### Test wrapper manually

Run the wrapper's command directly:

```bash
# Activate the conda environment
conda activate snakemake-wrappers-env

# Run the tool manually
toolname --input test.txt --output result.txt
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Tests fail with conda errors">
    **Problem**: Conda environment creation fails during tests.
    
    **Solution**:
    - Clear conda cache: `conda clean --all`
    - Update conda: `conda update conda`
    - Check network connectivity
    - Verify conda channels are accessible
  </Accordion>
  
  <Accordion title="Wrapper not found">
    **Problem**: Snakemake can't find your wrapper.
    
    **Solution**:
    - Check the wrapper path is correct
    - Ensure you're in the right directory
    - Verify the wrapper directory structure
    - Use absolute paths for testing
  </Accordion>
  
  <Accordion title="Import errors">
    **Problem**: Python import errors in wrapper.
    
    **Solution**:
    - Check all imports are available in environment.yaml
    - Verify import paths are correct
    - Test imports in the conda environment
  </Accordion>
  
  <Accordion title="Test data not found">
    **Problem**: Tests can't find test data.
    
    **Solution**:
    - Verify test data paths are relative to test directory
    - Check test data files exist
    - Ensure paths in Snakefile are correct
  </Accordion>
</AccordionGroup>
